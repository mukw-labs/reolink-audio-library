# Project logo

The original Reolink Audio Library mark combines an audio-file library with a
waveform. It is independent of Reolink and Home Assistant branding and is covered
by this repository's MIT license. It was generated using the built-in OpenAI
image-generation tool. Only transparent trimming, square sizing, downscaling and
metadata-free PNG export were applied afterwards.

Files:

- `docs/assets/logo.png`: 1024 × 1024 README artwork.
- `custom_components/reolink_audio_library/brand/icon.png`: 256 × 256 HA icon.
- `custom_components/reolink_audio_library/brand/icon@2x.png`: 512 × 512 HA icon.

The alpha channel is preserved. Local integration branding follows
[Home Assistant's image guidance](https://contributors.home-assistant.io/core/integrations/brands/).

## Generation prompt

```text
Use case: logo-brand. Asset type: original open-source GitHub project logo for Reolink Audio Library, a Home Assistant custom integration for managing saved camera audio recordings. Primary request: a polished minimal standalone icon combining a compact archive/library of audio files with a clear audio waveform. Style: crisp flat geometric vector-like artwork, strong silhouette, generous negative space, few solid shapes, readable at small icon sizes. Composition: a single centered square-format symbol, no surrounding mockup, transparent background. Color palette: deep navy with turquoise and sky-blue accents, restrained modern home-automation feel. Constraints: original independent identity, no Reolink corporate mark, no Home Assistant corporate mark, no microphone or live-talk symbol, no camera lens, no text, no letters, no watermark, no gradients or shadows. Produce one final logo, not a contact sheet. Preserve real alpha transparency.
```
